opentree Helm Charts

A Kubernetes Helm chart repository maintained by opentreecz. Charts are linted, unit-tested, and published automatically via chart-releaser.

Usage

helm repo add opentree https://opentreecz.github.io/helm
helm repo update
helm search repo opentree

Available Charts

ChartDescriptionSource
example-app Starter chart for a generic web application opentreecz/helm
tor-obfs4-bridge Tor obfs4 pluggable-transport bridge (StatefulSet + LoadBalancer) opentreecz/helm
wg-easy WireGuard VPN server with web UI (wg-easy) opentreecz/helm
wireguard WireGuard VPN – server and client mode (linuxserver/wireguard) opentreecz/helm
wordpress WordPress CMS with optional MariaDB / Redis / Valkey / Memcached subcharts opentreecz/helm
mc-router Minecraft Java Edition connection router (itzg/mc-router) opentreecz/helm
minecraft Minecraft Java Edition server (itzg/minecraft-server, 200+ options) opentreecz/helm
minecraft-bedrock Minecraft Bedrock Edition server (itzg/minecraft-bedrock-server) opentreecz/helm
minecraft-proxy Minecraft proxy – BungeeCord / Velocity / Waterfall (itzg/bungeecord) opentreecz/helm
rcon-web-admin Web RCON admin panel for game servers (itzg/rcon-web-admin) opentreecz/helm

Install an example

# Tor obfs4 bridge
helm install my-bridge opentree/tor-obfs4-bridge \
  --set config.email=you@example.org \
  --namespace tor --create-namespace

# Minecraft Java server
helm install my-mc opentree/minecraft \
  --set minecraftServer.eula=TRUE \
  --namespace minecraft --create-namespace

# WordPress
helm install my-wp opentree/wordpress \
  --set wordpress.url=https://myblog.example.org \
  --set mariadb.enabled=true \
  --namespace wordpress --create-namespace
